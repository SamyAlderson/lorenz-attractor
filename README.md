# Lorenz Attractor

Generates the Lorenz attractor and visualizes it using matplotlib

This project is a simple script to plot the Lorenz attractor, a classic example of chaos theory in action. The Lorenz attractor is a set of equations that describe the behavior of a system over time, and it's a great way to visualize the complex interactions between different variables.

## Install

You can install the project using pip:
```bash
pip install matplotlib numpy
```
## Usage

To run the project, simply execute the `lorenz_attractor.py` script:
```bash
python lorenz_attractor.py
```
This will generate a plot of the Lorenz attractor using matplotlib.

## Build from Source

If you want to build the project from source, you can clone the repository and run the following commands:
```bash
git clone https://github.com/SamyAlderson/lorenz-attractor.git
cd lorenz-attractor
python setup.py install
```
## Run Tests

You can run the tests using the following command:
```bash
python -m unittest discover
```
This will run all the tests in the `tests` directory.

## Project Structure

* `lorenz_attractor.py`: The main script that generates the Lorenz attractor and visualizes it using matplotlib.
* `tests`: A directory containing the test suite for the project.
* `setup.py`: A script that sets up the project for installation.
* `README.md`: This file.
